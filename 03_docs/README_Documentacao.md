## Rastreabilidade DAX
As medidas usadas pelo relatório foram identificadas diretamente na definição final do PBIX. Quatro expressões foram confirmadas no histórico de desenvolvimento; as demais estão registradas como lógica canônica/reconstruída para não apresentar como literal uma expressão que não pôde ser extraída byte-a-byte do DataModel comprimido neste ambiente.
